# 📚 Tech Glossary Hub

> An interactive technology glossary designed to help developers and learners understand important technology concepts through **simple definitions, syntax, and practical examples**.

Tech Glossary Hub organizes technical terms into focused categories and provides a **clean, responsive, beginner-friendly interface** for exploring and learning technology concepts.

---

## ✨ Key Features

- 📚 Technology glossary with dynamically rendered terms
- 🔎 Search and explore technology terms
- 🗂️ Category-based organization
- 📖 Definition, syntax, and practical example for each term
- 📱 Responsive design
- 🕷️ Spider-Man-inspired UI theme
- 🌙 Theme support
- 🔗 Dedicated term details
- 🌐 Multiple project versions
- 💻 Live previews of other versions through iframes
- ♿ Accessibility-focused interface
- 🚀 SEO-friendly structure

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

---

## 📂 Categories

Tech Glossary Hub currently contains **5 major technology categories**:

1. **Web Development & Design**
2. **Software Engineering**
3. **Data Science & AI**
4. **Cybersecurity**
5. **Cloud & Networking**

Each category contains **15–20 technology terms**.

Every term provides:

- 📖 Definition
- 💻 Syntax
- 🛠️ One practical example
